# 🚀 Power BI Dashboard: QC Variance Analysis

📖 Overview

Designed and implemented a QC Variance Dashboard in Power BI to monitor and analyze quality control performance for September 2023. The dashboard provides actionable insights to improve operational efficiency by visualizing critical metrics related to quality control processes.

✨ Key Features

📊 Delivered Percentage Analysis:
Tracked and visualized the percentage of tasks delivered on time, helping identify patterns and trends in task completion rates.

⚠️ Error Rate Monitoring:
Displayed error rates across processes to highlight areas requiring immediate attention and allowed stakeholders to mitigate errors proactively.

📈 Backlog Management:
Visualized pending tasks and their trends to support backlog reduction strategies and enable effective resource allocation.

👷 QC Capacity Utilization:
Analyzed capacity metrics to determine operational efficiency and highlighted under- or over-utilized resources.

🎯 Objective

The dashboard was developed to:

Provide real-time visibility into quality control performance.
Identify operational bottlenecks affecting efficiency and accuracy.
Enable data-driven decision-making for process improvement.

🛠️ Tools & Technologies

Power BI:
Interactive data visualization and dashboard creation.
Slicers and filters for deep-dive analysis.
DAX (Data Analysis Expressions):
Created calculated fields and measures (e.g., Delivered %, Error Rates).

Power Query:
Performed data transformation and modeling.

Data Sources:
CSV files and SQL databases for QC data processing.

🔍 Insights and Impact
Achieved a 📉 10% improvement in error rates by addressing identified bottlenecks.
Reduced backlogs by 🕒 20%, improving resource utilization and task prioritization.
Enhanced real-time visibility into operations, enabling faster, more informed decision-making.
